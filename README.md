# ドラゴンボール アドオン（Minecraft 統合版・個人用）

`MASTER_PROMPT.md` の内容をもとに作った、ドラゴンボールの世界を遊べるアドオンです。
修行で強くなり、舞空術で空を飛び、かめはめ波を撃ち、変身し、原作の敵と戦いながらドラゴンボールを集めます。

- 対応バージョン：Minecraft 統合版 **1.26.30 以降**
- 個人で遊ぶためのものです（配布用ではありません）

---

## 1. 導入方法

1. `dist/DragonBall.mcaddon` をダウンロードします。
2. ファイルを開く（ダブルクリック、またはスマホなら「Minecraft で開く」）と、ビヘイビアパックとリソースパックが自動で読み込まれます。
3. ワールドを新しく作る（または既存のワールドの「編集」を開く）。
4. **アドオン**（ビヘイビアパック）で「ドラゴンボール ビヘイビア」を有効にします。リソースパックも一緒に有効になります。
5. 実験的機能は**オンにしなくて大丈夫**です。
6. ワールドに入ると種族選択の画面が出ます。

> スクリプトで動くアドオンなので、「チート」をオンにする必要はありません。

### ワールドで有効にしたほうがいい設定

- 特になし。地形破壊やPvPなどは、ゲーム内のメニュー（ドラゴンメニュー →「ワールド設定」）で切り替えます。

## 2. 操作方法

種族を選ぶと、ホットバーに操作アイテムが入ります（死んでもなくなりません）。

| スロット | アイテム | 使い方 |
|---|---|---|
| 1 | 気溜め | **長押し**で気を溜める。**しゃがみ＋使用**で「気を消す」の切り替え |
| 2〜5 | 技スロット A〜D | 押すと技を出す。気功波は**長押しで溜めて、離すと発射** |
| 6 | 変身 | 押すたびに1段階変身。**しゃがみ＋使用**で解除 |
| 7 | ガード | **長押し**でガード。攻撃を受ける直前に押すと**ジャストガード**（相手の背後に回り込む） |
| 8 | ドラゴンメニュー | ステータス・技・変身・ストーリー・仲間・設定など |

| 動き | 操作 |
|---|---|
| 舞空術 | 空中でもう一度ジャンプ |
| 上昇／下降 | ジャンプ長押し／しゃがみ長押し |
| 高速飛行 | 飛行中にダッシュ（スプリント）で前進 |
| 着地 | 地面でしゃがむ／しばらく地面に立つ |
| 高速移動（残像） | しゃがみを素早く2回 |
| 追撃 | コンボのフィニッシュ直後に、しゃがみ2回 |
| 格闘コンボ | 素手で殴り続ける（5発目がフィニッシュ） |
| ビームの押し合い | ジャンプを連打 |
| 瞑想 | しゃがんだまま3秒じっとする（気が早く回復し、経験値が入る） |

- スマホ（タッチ）、コントローラー、キーボードとマウスのどれでも同じ操作で遊べます。
- アイテムをなくしたら、メニューの「道具を受け取る」か、コマンド `/dbz:dbkit` で受け取り直せます。
- `/dbz:dbmenu` でメニュー、`/dbz:dbhelp` で遊び方を表示できます。
- `/dbz:dbbattle` でモブバトルの道具一式を受け取り、バトル管理メニューを開けます。

## 5. 世界の遊び方

- **名所**：世界の始まりの場所のまわりに、パオズ山（悟空の家）、カメハウス、カプセルコーポレーション、カリン塔と神様の神殿、天下一武道会の会場、レッドリボン軍の基地、セルゲームの会場があります。近づくと建物が現れます。
- **宇宙**：ブルマから宇宙船のカプセルをもらうと、ナメック星・界王星・破壊神ビルスの星・力の大会の会場へ行けます。
- **修行**：重力室（重力を上げるほど経験値アップ）、精神と時の部屋（経験値3倍）、界王星（経験値2倍）、重りの道着、サンドバッグ、瞑想。
- **ストーリー**：メニューの「ストーリー」から、ラディッツ襲来〜力の大会のジレンまで18章。
- **ドラゴンボール**：ブルマのドラゴンレーダーで探して7つ並べ、ボールを使うと神龍。願いを叶えるとしばらく石になります。
- **天下一武道会**：会場のアナウンサーに話しかけると出場。4連勝で優勝。
- **スポーンエッグ**：クリエイティブのインベントリ（自然 →「スポーンエッグ」）に、全キャラ（75体）のスポーンエッグがあります。地面に使うとその場所、空中に使うと目の前に出てきます。
  - 敵キャラ（ラディッツ・フリーザ・セル・魔人ブウ・ブロリー・ジレンなど）は**敵**として出てきて襲ってきます。
  - それ以外（悟空・ベジータ・ピッコロ・ビルスなど）は**中立**で出てきます。話しかけると会話や手合わせができます。
  - **しゃがみながら使う**と逆になります（悟空を敵として出して戦う、フリーザをおとなしく出す、など）。
  - サバイバルでは使うと1個減ります。
- **仲間**：手合わせで勝ったキャラ（悟空・悟飯・悟天・ベジータ・トランクス・ピッコロ・クリリン・天津飯・ヤムチャ）は仲間にでき、一緒に飛んで戦い、ピンチの時は仙豆をくれます（最大3人）。

## 6. モブバトル（キャラ同士を戦わせる）

ドラゴンボールのキャラ同士や、普通のモブも混ぜて戦わせられます。道具はクリエイティブのインベントリ（装備）にあるほか、`/dbz:dbbattle` かバトル管理メニューの「道具を受け取る」でまとめて受け取れます。クリエイティブで遊ぶのがおすすめです。

| 道具 | 使い方 |
|---|---|
| チームの旗（赤・青・緑・黄） | キャラやモブを叩くとそのチームに入る。違うチームどうしが自動で戦う。しゃがんで叩くとバトルから外す。空中で使うと自分がチームに入る（しゃがみ＋使用で抜ける） |
| 一騎打ちの杖 | 2体を順番に叩くと、その2体だけで戦う |
| 集団戦の杖 | 仲間を叩いて選び（もう一度叩くと選択解除）、しゃがみながら標的を叩くと全員で襲いかかる |
| 回復の杖 | 叩いた相手を全回復。しゃがんで叩くと周りの参加者全員 |
| 撃破の杖 | 叩いた相手を倒す（プレイヤー以外） |
| 強化の杖 | 力・速さ・耐性・再生を60秒。しゃがんで叩くと効果を消す |
| バトル管理 | 一時停止／再開、味方への攻撃のあり・なし、体力表示、近くの参加者の解散・全員撃破、遊び方 |

- 参加中は名前の上に `[赤]` `[一騎打ち]` などの印と体力が出ます。
- チーム戦は最後の1チームが残ったとき、一騎打ちと集団戦は決着がついたときに、勝者が表示されます。
- ドラゴンボールのキャラは、殴り飛ばし・ラッシュ・飛び退き・空中戦をしながら、気功波・ビーム・瞬間移動・変身も使って戦います。普通のモブは近づいて殴り合います（クリーパーは近づくと爆発します）。
- 一騎打ちと集団戦は、同時に8件までです。
- 道具で叩いてもダメージは入りません。

## 7. 統合版の制約で代わりの方法にした部分

| マスタープロンプトの内容 | 実際の作り |
|---|---|
| 専用の画面表示（HUD） | 統合版は画面の部品を自由に足せないため、画面下のアクションバーに「体力・気ゲージ・戦闘力・変身・技スロット」を表示 |
| 変身時に髪・体・目が変わる | プレイヤーの体に「髪」「体の上着」「オーラ」「尻尾」の層を重ねて表示。大猿は体ごと別モデルに入れ替え。目の色は顔の上書き（超サイヤ人4・ナメック星人など一部のみ） |
| キー操作 | 統合版は自由なキー割り当てができないため、ホットバーの操作アイテム＋ジャンプ／しゃがみの組み合わせで操作 |
| ナメック星・界王星などの別の星 | 統合版では新しいディメンションを作れないため、同じワールドの遠く離れた場所（数万ブロック先）に星を作り、霧の色で雰囲気を出している。ナメック星は周りの地形を青い草とアジッサの木に作り変える |
| 空の色（ナメック星の緑の空） | 空そのものは変えられないため、緑色の霧で表現 |
| 精神と時の部屋の「中の1日は外の1年」 | 時間の流れは変えられないため、経験値3倍と「外の世界の◯日分」の表示で表現 |
| 名所の建物 | 構造物ファイルの代わりにスクリプトで組み立てる。プレイヤーが近づいたときに建つ |
| 不老不死 | 死そのものは防げないため、体力が2割5分を切ると一瞬で全快し、しばらく無敵になる |
| フュージョンの「ポーズを合わせる」 | NPCの仲間とはタイミング演出（動いたりしゃがむと失敗しやすい）。失敗すると太った姿かガリガリの姿になる |
| 効果音・BGM | 原作の音は使わず、それっぽい効果音をプログラムで合成して収録 |
| ボスの体力ゲージ | 統合版のボスバー（画面上部）を使用 |
| 大技で視点が引く | 一時的に三人称視点に切り替えて表現 |

## 8. 作り直し方（開発用）

```
pip install pillow numpy   # ffmpeg も必要
python3 tools/gen/build.py # packs/ と dist/DragonBall.mcaddon を生成
cd tools && npm install && npm run check   # スクリプトの型チェック
node --import ./test/loader.mjs test/smoke.mjs    # 動作テスト（モック）
node --import ./test/loader.mjs test/smoke2.mjs
python3 test/validate_packs.py              # 参照切れチェック
```

- モデル・テクスチャ・効果音・パーティクルなどは `tools/gen/` のスクリプトから自動生成しています。
- ゲームの動きは `packs/DragonBall_BP/scripts/` の JavaScript（Script API）です。
